mend applies AI-written edits in four formats — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON text-editor tool calls — to a tree of text files, tolerating drifted line numbers, whitespace and indentation; every file changes or none does.

## Run it

```sh
node main.ts fix.patch
```
